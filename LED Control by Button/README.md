# SIG3-Day-2
Button-Controlled LED – Read a push-button and toggle an external LED with basic software debouncing.

## Problem Description:
The Problem is to glow the built in led in ESP32 at constant ON and OFF intervals like one time ON and one time OFF along with push button which helps to access the external LED control with remote access. For this problem, I had used Wokwi Simulator which is a virtual simulator, helps me in interactive simulation and gives me practical exposure befor testing on hardware.
