# SIG3-Day-4
PWM Fade – Control LED brightness using PWM based on a potentiometer reading.

## Problem Description:
The Problem is to control the amount of power or simulate analog signals sent to a device by rapidly turning a voltage on and off by using PWM(Pulse Width Modulation) Technique.In this case, I had used Potentiometer to adjust the amount of voltage to be supplied for the external LED which indicates the amount of power through the brightness.For this problem, I had used Wokwi Simulator which is a virtual simulator, helps me in interactive simulation and gives me practical exposure befor testing on hardware.
