# SIG3-Day-1
Blink Challenge – Blink the ESP32 built-in LED at 1-second intervals and simulate it in Wokwi before testing on hardware.

## Problem Description:
The Problem is to glow the built in led in ESP32 at 1-second intervals like creating time delays for ON and OFF operations. For this problem, I had used Wokwi Simulator which is a virtual simulator, helps me in interactive simulation and gives me practical exposure befor testing on hardware.
