# SIG3-Day-2
Button-Controlled LED Toggle Challenge – Control an external LED using a push button on the ESP32. Each button press toggles the LED state (ON/OFF). The circuit was first simulated in Wokwi before testing on actual hardware.

## Problem Description:
The objective of this challenge is to control an LED using a push button connected to the ESP32. Whenever the button is pressed and released, the LED changes its current state. If the LED is OFF, it turns ON. If the LED is ON, it turns OFF.

To understand the behavior before implementing it on physical hardware, I used the Wokwi Simulator. This helped me visualize the circuit connections, test the button toggle logic, and verify the output safely in a virtual environment.
